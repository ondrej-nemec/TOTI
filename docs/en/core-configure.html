Configuration

Both server and aplication can be let in default settings, can be set using configuration file or can be set in code.
Configuration file can be in XML or Properties format. File configuration override default configuration. Code settings override default and file configuration. If value is set to null, default value is used.
File configuration is applied if TotiServerFactory is created with parameter: new TotiServerFactory("/path/to/file"). Path can be absolute or relative. File can be in classpath(compiled to jar) or outside of jar.

Server

Charset

Set charset of all data transfer.
Default value: UTF-8
Set in code: setCharset()
Set in properties: http.charset
Set in XML: 

<root>
    <http>
        ...
        <charset>...</charset>
    </http>
</root>

HTTP port

Set port to be used for HTTP communication. Value 0 (or below) disable HTTP.
Default value: 80
Set in code: setHttpPort
Set in properties: http.port
Set in XML: 

<root>
    <http>
        ...
        <port>...</port>
    </http>
</root>

HTTPS port

Set port to be used for HTTPS. Value 0 (or below) disable HTTPS.
Default value: 443
Set in code: setHttpsPort
Set in properties: http.secured-port
Set in XML: 

<root>
    <http>
        ...
        <secured-port>...</secured-port>
    </http>
</root>

SSL certificates

Set certificates. If no certificates provided, HTTPS is disabled.
Server needs path to its own certificate key store and password and key store type as well.
Optionally, if sni host is checked can be set (True in default).
Trusted clients can be set. Path to certificate store, password and store type are required.
If no trusted clients certificate store is provided, server trusts all clients.
Default value: Optional.empty()
Set in code: 

SslCredentials cred = new SslCredentials();
cred.setCertificateStore("...", "...", "...");
cred.setSniHostCheck(...);
cred.setTrustedClientsStore("...", "...", "...");
cred.setTrustAll(...);
serverFactory.setCerts(Optional.of(cred));
Set in properties:
http.key-store.path
http.key-store.password
http.key-store.type
http.key-store.checkSNI
http.trust-store.path
http.trust-store.password
http.trust-store.type
Set in XML: 

<root>
    <http>
        ...
        <key-store>
            <path>...</path>
            <password>...</password>
            <type>...</type>
            <checkSNI>...</checkSNI>
        </key-store>
        <trust-store>
            <path>...</path>
            <password>...</password>
            <type>...</type>
        </trust-store>
    </http>
</root>

Default value: 60 000
Set in code: setReadTimeout
Set in properties: http.read-timeout
Set in XML: 

<root>
    <http>
        ...
        <read-timeout>...</read-timeout>
    </http>
</root>

Max request body size

Max allowed size of request body. Value NULL means no max value.
Default value: null
Set in code: setMaxRequestBodySize
Set in properties: http.max-request-size
Set in XML: 

<root>
    <http>
        ...
        <max-request-size>...</max-request-size>
    </http>
</root>

Thread pool

Size of thread pool available to handle client requests at one moment.
Default value: 5
Set in code: setThreadPool
Set in properties: http.thread-pool
Set in XML: 

<root>
    <http>
        ...
        <thread-pool>...</thread-pool>
    </http>
</root>
