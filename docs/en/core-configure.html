Configuration

Both server and aplication can be let in default settings, can be set using configuration file or can be set in code.
Configuration file can be in XML or Properties format. File configuration override default configuration. Code settings override default and file configuration. If value is set to null, default value is used.
File configuration is applied if TotiServerFactory is created with parameter: new TotiServerFactory("/path/to/file"). Path can be absolute or relative. File can be in classpath(compiled to jar) or outside of jar.

Server

Charset

Set charset of all data transfer.
Default value: UTF-8
Set in code: setCharset()
Set in properties: http.charset
Set in XML: 

<root>
    <http>
        ...
        <charset>...</charset>
    </http>
</root>

HTTP port

Set port to be used for HTTP communication. Value 0 (or below) disable HTTP.
Default value: 80
Set in code: setHttpPort
Set in properties: http.port
Set in XML: 

<root>
    <http>
        ...
        <port>...</port>
    </http>
</root>

HTTPS port

Set port to be used for HTTPS. Value 0 (or below) disable HTTPS.
Default value: 443
Set in code: setHttpsPort
Set in properties: http.secured-port
Set in XML: 

<root>
    <http>
        ...
        <secured-port>...</secured-port>
    </http>
</root>

SSL certificates

Set certificates. If no certificates provided, HTTPS is disabled.
Server needs path to its own certificate key store and password and key store type as well.
Optionally, if sni host is checked can be set (True in default).
Trusted clients can be set. Path to certificate store, password and store type are required.
If no trusted clients certificate store is provided, server trusts all clients.
Default value: Optional.empty()
Set in code: 

SslCredentials cred = new SslCredentials();
cred.setCertificateStore("...", "...", "...");
cred.setSniHostCheck(...);
cred.setTrustedClientsStore("...", "...", "...");
cred.setTrustAll(...);
serverFactory.setCerts(Optional.of(cred));
Set in properties:
http.key-store.path
http.key-store.password
http.key-store.type
http.key-store.checkSNI
http.trust-store.path
http.trust-store.password
http.trust-store.type
Set in XML: 

<root>
    <http>
        ...
        <key-store>
            <path>...</path>
            <password>...</password>
            <type>...</type>
            <checkSNI>...</checkSNI>
        </key-store>
        <trust-store>
            <path>...</path>
            <password>...</password>
            <type>...</type>
        </trust-store>
    </http>
</root>

Application

All file settings contains application unique in the path. In examples, 'demo' will be used as application unique.

Allow dir list

In case a URI pointing to resources directory but not pointing to file but folder, this flag signalize if content of folder can be listed on page.
Default value: false
Set in code: setDirResponseAllowed
Set in properties: applications.demo.dir-allowed
Set in XML: 

<root>
    <applications>
        ...
        <demo>
            ...
            <dir-allowed>...</dir-allowed>
        </demo>
    </applications>
</root>

Default file in directory

In case listing directory is not allowed and URI pointing to folder, this file (in the folder) will be showed. NULL value means no file will be used.
Default value: index.html
Set in code: setDirDefaultFile
Set in properties: applications.demo.dir-default-file
Set in XML: 

<root>
    <applications>
        ...
        <demo>
            ...
            <dir-default-file>...</dir-default-file>
        </demo>
    </applications>
</root>

Resources path

Path to folder on disk where are resources files. This path is root for resources.
Default value: www
Set in code: setResourcesPath
Set in properties: applications.demo.resource-path
Set in XML: 

<root>
    <applications>
        ...
        <demo>
            ...
            <resource-path>...</resource-path>
        </demo>
    </applications>
</root>

Response headers

Headers returned with every response.
Default value: Access-Control-Allow-Origin: *
Set in code: setHeaders
Set in properties:
applications.demo.headers.1
applications.demo.headers.2
...
Set in XML: 

<root>
    <applications>
        ...
        <demo>
            ...
            <headers>
            	...
            	<header>...</header>
            	<header>...</header>
            </headers>
        </demo>
    </applications>
</root>

Logs path

Path where TOTI will be saving detailed error files. Emptry string means no saving.
Default value: logs/<appIdentifier>
Set in code: setLogsPath
Set in properties: applications.demo.logs-path
Set in XML: 

<root>
    <applications>
        ...
        <demo>
            ...
            <logs-path>...</logs-path>
        </demo>
    </applications>
</root>

Is application in dev mode

TOTI can response in two modes: DEV and PROD. In PROD, TOTI shows less information about errors on page. In DEV, TOTI shows as much as possible information about exceptions etc.
The mode can be selected for given request. TOTI provide request IP for selection mode.
Default value: ip->ip.equals("127.0.0.1") || ip.equals("0:0:0:0:0:0:0:1")
Set in code: setDevModeFunc
Set in properties: Cannot be set
Set in XML: Cannot be set

Auto start

Flag signalize if application should automatically start with TotiServer.
Default value: true
Set in code: setAutoStart
Set in properties: applications.demo.autostart
Set in XML: 

<root>
    <applications>
        ...
        <demo>
            ...
            <autostart>...</autostart>
        </demo>
    </applications>
</root>
