Preparations

The tutorial expected you have created Java Gradle project with dependency on TOTI Core. TOTI use Log4j2 so you will probably need dependency on some implementation of it.

Initialize server

We start with creating TotiServerFactory. This class helps with configuring a server. You can create it with given path to configuration file or with properties or without parameters to use default configuration or to set it manualy in code. For now, we let everything default.
From TotiServerFactroy we create TotiServer. If we call start, our program will be listening on ports 80 and 443.
Our class can look like this: 

public class GetStartedMain {
	
	private final Logger logger;
	private final TotiServer server;

	public GetStartedMain() {
		this.logger = LogManager.getLogger("toti-get-started");
		TotiServerFactory serverFactory = new TotiServerFactory();
		// there can be server configuration
		this.server = serverFactory.create(logger);
	}

	public void start() {
		try {
			server.start();
		} catch (Exception e) {
			logger.fatal("GetStarted:start fails", e);
		}
	}

	public void stop() {
		try {
			server.stop();
		} catch (Exception e) {
			logger.fatal("GetStarted:stp fails", e);
		}
	}

	public static void main(String[] args) {
		// no need to call stop - this is just demo stopped from IDE
		new GetStartedMain().start();
	}

}
Our program is binding ports, but all requests return 404.

Applications

Application from TOTI perspective is one application running on web server (TotiServer). One server can has more applications. You can add or remove Application from server before or after server start. Here we will add our application right after server create. 

server.addApplication("getStarted", (env, applicationFactory)->{
	// there can be application configuration
	applicationFactory.setDevModeFunc(ip->true); // dev mode
	return applicationFactory.create(Arrays.asList(), logger);
}, null, null);
First argument is unique name for you application. Second is callback. Callback provide env (part of server env relatet to your application) and application factory (allows configure application). A result is new Application created from applicationFactory. Last two arguments are used if you have more applications. Can stay null here.
create method requires list of Modules and logger. List can be empty.
Also, we set the application to develop mode. In develop mode, TOTI displays more information in browser.
Now, if you restart your program and make request you get... 404. But now, you can see more details.
Just verify TOTI is working, try use /toti as URI. You should see TOTI welcome page.

HTML, CSS, JS, Images etc

Now, create folder with name www in your application root and then create file with name index.html inside the folder. 

	>!DOCTYPE html<
	>html<
	>head<
		>meta charset="utf-8"<
		>meta name="viewport" content="width=device-width, initial-scale=1"<
		>title<Hello World>/title<
	>/head<
	>body<
		>h1<Hello World!>/h1<

	>/body<
	>/html<
If you just refresh your page - no program restart needed, you will see your Hello World page.
www is resource folder - everything inside is available from browser.
