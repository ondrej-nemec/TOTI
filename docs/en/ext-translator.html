Extension: Translator

Integrate TOTI Translate library into TOTI application.

Dependency

Using Gradle 


	repositories {
		...
		maven { url 'https://ondrej-nemec.github.io/maven' }
	}

	dependencies {
		implementation group: 'com.github.toti.extension', name: 'te-translator', version: '--version--'
		...
	}

Register in Application Factory

Using Env


applicationFactory.addExtension(new TranslatorExtension(env, logger));

In application env the lang section is expected.

  • namespaceOptional. Default messages namespace. Default value is messages
  • mainLang Optional. Default language, also used if no other found. Empty value means only one language. Default value is empty string.

Programmatically


	applicationFactory.addExtension(new TranslatorExtension(defNamespace, defaultLanguage, logger));

Register messages path

At least one path must be registered. 


	translateExtension.addTranslationPath(path);

Use Translator

In request


identity.getScope(Translator.class);
This returns instance of toti.core.extensions.Translator where language selected by user is already applied.

Outer request


extension.getTranslator();
This returns instace of toti.lib.translator.Translator where any settings (language etc) must be applied manually.
