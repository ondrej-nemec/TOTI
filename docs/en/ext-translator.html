Register in Application Factory

Using Env


applicationFactory.addExtension(new TranslatorExtension(env, logger));

In application env the lang section is expected.

  • namespaceOptional. Default messages namespace. Default value is messages
  • mainLang Optional. Default language, also used if no other found. Empty value means only one language. Default value is empty string.

Programmatically


	applicationFactory.addExtension(new TranslatorExtension(defNamespace, defaultLanguage, logger));

Register messages path

At least one path must be registered. 


	translateExtension.addTranslationPath(path);
