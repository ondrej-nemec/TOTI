Library: Database

Manage database connections, helps keep database up-to-date and provide API for SQL queries in different SQL mutations.

Dependency

Using Gradle 


	repositories {
		...
		maven { url 'https://ondrej-nemec.github.io/maven' }
	}

	dependencies {
		implementation group: 'toti.TOTI.lib', name: 'toti-database', version: '--version--'
		...
	}
