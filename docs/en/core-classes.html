Register, Router and Link

Register

Register serves to few purposes. First, there is controller registration. Second, allows share instances between modules. Third, gives access to extensions.

Controller


	register.addController(MyController.class, ()->new MyController())

Share instances

Register allows share created instance of class: 

MyClass myClass = ...;

// register
register.addService(myClass);
// check for existence
register.isServicePresent(MyClass.class);
// receive
MyClass myClass = register.getService(MyClass.class);

// OR

// register
register.addService("SharedClass", myClass);
// check for existence
register.isServicePresent("SharedClass");
// receive
MyClass myClass = register.getService("SharedClass", myClass);
Sharing factory to creating new instance is also posible: 

// register
register.addFactory(()->new MyClass());
// check for existence
register.isFactoryPresent(MyClass.class);
// receive
MyClass myClass = register.getFactory(MyClass.class); // new instance every time

// OR

// register
register.addFactory("SharedMethod", ()->new MyClass());
// check for existence
register.isFactoryPresent("SharedMethod");
// receive
MyClass myClass = register.getFactory("SharedClass", MyClass.class); // new instance every time

Obtaining extension

If application has registred some extension, register allows access them: 

register.getExtension(MyExtension.class);

Router

By default, TOTI use link in format /[module]/[controller]/[action]/{params}. All values are optional, but each route + HttpMethod must be unique.
Class Router allows create static mapping between routes. For example, allows automatically redirect / to some defautl or home page. 

router.addUrl("/", "/core/home/index");

Custom routes

Create own routes pattern is possible. It requires instance of UriPattern and override createuri method. Then, the instance must be registered: applicationFactory.setUrlPattern(uriPattern)

Link

This class allows generate links inside application. Generation requires Class (must be registered as controller in Register) and method calling where action is called. The calling will not be performed, it is just mock calling. 

// link to MyController to method 'index'
String href = link.create(MyController.class, c->c.index());
// and with query parameters
String href = link.create(MyController.class, c->c.index(), MapInit.create().append("key", "value").toMap());
// with path params
String href = link.create(MyController.class, c->c.index(null, null), 123, true);
// with query and path params
String href = link.create(MyController.class, c->c.index(null, null), MapInit.create().append("key", "value").toMap(), 123, true);

Custom exception handler

Custom Exception handler is controller that implements CustomErrorHandler. The controller must be registered. Custom handling is performed only if request is not develop.
Example 

@Controller("error")
public class ErrorHandlerExampleController implements CustomErrorHandler {

	@Override
	public ResponseAction onError(StatusCode status, Throwable t) {
		return (request, identity)->{
			return Response.create(status).getText("Ups, something happend: " + t.getMessage());
		};
	}

}
