Extension: Database

Extension includes TOTI Database lib to project. Calling migrate() method is automatic during application start.

Register in Application Factory

Using Env


	applicationFactory.addExtension(new DatabaseExtension(logger));

In application env the database section is expected.

  • type of database engine
  • url
  • schema-name
  • login
  • password
Except that, also section options can be included. If so, all elements from the section are used as name-value pair to set configuration property.

Programmatically


	applicationFactory.addExtension(new DatabaseExtension((migrationPaths, env)->{
		// TODO return database instance
	}, logger));

env is database section of application env.

Migrations

Migration path can be added like this: databaseExtension.addMigrationPath(path).

Another way is add migration path for each module (called in initInstances): register.getExtension(DatabaseExtension.class).addMigrationPath(path).

Get Database instance

Database instance is available at: register.getExtension(DatabaseExtension.class).getDatabase().
