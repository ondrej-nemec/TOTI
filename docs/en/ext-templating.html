Extension: Templating

Integrate TOTI Templating library into TOTI application.

Register in Application Factory

Using Env


applicationFactory.addExtension(new TemplateExtension(env, logger));

In application env the templating section is expected.

  • temp path to temp
  • minimalize-templates if templates should be minimalized (usually false)
  • delete-temp-java if delete unused temporal files (usually false)

Programmatically


	applicationFactory.addExtension(new TemplateExtension(
		tempPath, minimalizeTemplate, deleteAuxFiles, logger
	));

Register template path

At least one module must be registered. 


	templateExtension.registerModule(moduleName, templatesPath);

Tags and parameters

Extension add some tags and parameters.

Tags

If current

Check if current page match / not match give parameters. Standart else tag can be inside ifcurrent pair.

Tag: ifcurrent
Paired: yes
Parameters

  • not: Optional flag. If present, tag is in NOT MATCH mode.
  • module: Optional. If present, the module name is check.
  • controller: Optional. If present, controller className is check.
  • method: Optional. If present, method name is check.

Link

Generate link to another page in application by given parameters.

Tag: link
Paired: no
Parameters

  • controller: full class name of controller.
  • method: method name. If path parameters are needed (/controller/method/paramX), add each as methodName:param1:param2.
All other params will be used as query params (key=value).

Permission

Check if current user has permissions. Standart else can be used.

This tag can be used only if Authorize is set to extension: templateExtension.setAuthorize(...);.

Tag: allowed
Paired: both. Not paired works as if without braces.
Parameters

  • not: Optional flag. If present, tag is in NOT ALLOWED mode.
All other parameters are send to Authorize:isAllowed as params.

Translate

Translate given message using application Translator.

Tag: trans
Paired: no
Parameters

  • message: text to translate.
All other params will be used as variables.

DateTime format

DEPRECATED.

Tag: format
Paired: no
Parameters

  • value: datetime
  • format: translation key for required format - can be different in different language.

Parameters

Alt

img parameter for translated alternative text.

Parameter: alt

Href

Generate href link in application. Expected value format: [controllerClassName]:[methodName]. Optionally, any path or query parameter can be added: :param1 or key=value.

Parameter: href

Src

Generate src link in application. Expected value format: [controllerClassName]:[methodName]. Optionally, any path or query parameter can be added: :param1 or key=value.

Parameter: src

Placeholder

input parameter for translated placeholder text.

Parameter: placeholder

Title

Parameter for translated on hover text.

Parameter: title
