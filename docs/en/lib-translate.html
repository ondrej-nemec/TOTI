Library: Translate

Provide localization from files. Allowed formats: xml, properties.

Translator class is constructed with Set of paths where translation files are stored. Optionaly you can set namespace (default: messages) and language (default is empty - not selected) too.

How it works

When you request translation for given key, package looks for files for given namespace and language. If no language is selected, expected filename format is: namespace.format. If language is selected, expected filename formats are: namespace.format and lang/namespace.format.

There can be more files with same namespace and language in given paths. Or you can combine XML and Properties file in one path. In result all data will be merged. 


	Translator t = new Translator(...);
	String translatedText = t.translate(key);

If no key is found, original key is returned.

key refers to text in file given by namespace, see examle below. If you want use another namespace, you can either use format: namespace:key or switch Translator to another namespace (t.withNamespace(...)).

Translator always use selected language. If you with switch to another, use t.withLang(...).

Example

Properties file 

hello-world=Hello World
common.yes=Yes
common.no=No


<root>
	<hello-world>Hello World</hello-world>
	<common>
		<yes>Yes</yes>
		<no>No</no>
	</common>
</root>

In both cases, keys are hello-world, common.yes and common.no.

Variables

Package allows parametrized your messages. The second optional parameter to translate method is Map<String, Object>. This map contains variables. If map is provided, package looks, if translated text contains any of key from map in format: %mapKey%. If so, package replace given placeholder with value.

Example 

	Translator t = ...;

	Map<String, Object> parameters = new HashMap<>();
	parameters.put("age", 42);
	parameters.put("name", "Jane Doe");

	// in file, value for key is: %title% %name% is in age of 20
	String message = t.translate("personal-info.lady-age");
	// message: %title% Jane Doe is in age of 20

As you can see from examle, age variable was not used. Also parameters miss variable title, so it stays as is.
