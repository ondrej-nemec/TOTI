Inputs

All inputs contains following methods:
  • setData(string name, object value)
  • getData(string name): object
  • getName(): string
  • getType(): string
  • getContainer(): Node
  • getValue(): object
  • setValue(object value, string source = null)
  • parseValue(object value): value
  • clear(string source = null)
  • onChange(callback, string source = null)
  • getTitle(): string
  • isExcluded(): bool
  • setExcluded(bool isDisabled)
  • isRequired(): bool
  • setRequired(bool isRequired)
  • isDisabled(): bool
  • addError(string error, object params = {})
  • getErrors(): object
  • clearErrors()
  • isValid(): bool
  • addValidation(name, callback)

Optional inputs

Some inputs can be optional. It means they are used or not depending on user choise.
  • setUsed(bool isUsed)
  • isUsed(): bool
  • setRequired(bool isRequired) cannot be called

OptionInput

Represent one item in list of options (f.e. in select).
  • addChild(OptionInput child)
  • getParent(): OptionInput|null
  • isSelectable(): bool
  • getInput(): Node
  • getKey(): string
  • getChild(key): OptionInput

OptionsInput

Represent input with options to select - select box and radio list.
  • getSelected(): OptionInput
  • afterOptionLoad(callable then)
  • getOptions()

StandartInput

Represent basic input.
  • _isValueMissing()

CheckInput

Represent input with boolean value.
  • _isValueMissing()

TextAreaInput

Represent text area input.

RangeInput

Represent range input.

TextInput

Represent text input.
  • getOptions()

FileInput

Represent file input.

HiddenInput

Represent hidden input.

ColorInput

Represent color input.

DatetimeInput

Represent inputs for date and/or time: date, time, datetime, week and month.

RadioListInput

Represent radiolist.

SelectInput

Represent select.
  • _parentChanged(parentValue)
  • __findParent(parent)

DynamicInput

Container with inputs. User can add/remove inputs.
  • addField()
  • removeField(index = null) remove input on given index. If null, last input is removed.
  • _isValueMissing()

InputList

Container with inputs. Inputs cannot be changed by user.
  • _isValueMissing()

LoadedList

Container with inputs. Inputs are defined by given template and loaded parameters.
  • _isValueMissing()

SubmitInput

Represent inputs for submiting form: submit a image.
  • getSubmitPolicy()
  • setSubmit(configuration, element)
  • submit()

Button

Represent button.
  • onClick(callable callback)
  • click()

Utils


Toti.utils

Clone

clone(data): object creates and returns copy of given data.

Random

random(max = 10000000): int creates random integer in range from 0 to given max number.

Sleep

sleept(millis): Promise. The Promise waits given miliseconds before continue.

Unaccent

unaccent(string): string returns new string where any letter with accent (like ě, é, ë) are replaced with same letter without accent (in this case: e)

PametrizedString

parametrizedString(string, object params): string looks for all keys of params in string (need to be in format {key}) and replaces them with given value.

CapitalizeFirstLetter

capitalizeFirstLetter(string): string returns given string with first letter being capital.

Execute

execute(callback, args = [], evaluate = false) executes given callback with given arguments and returns result. callback can be
  • Function
  • Name of registered Toti callback
  • Name of defined function in global scope
  • JS script (to run string as script, evaluate must be set to true)

OptionalConf

Primary for internal use
optionalConf(objcet configuration, string name, callback, result) check if configuration contains name. If so, value is set to result. If not, given callback is set to result.

Dialog

Set of interaction with user. 

Toti.dialog

Alert

alert(message): Promise shows given message. There is no value in Promise result.
Override 

{
	...,
	dialog: {
		...,
		alert: func(string): Promise
	}
}

Prompt

prompt(message, defValue = ""): Promise shows given message as prompt. The promise response data are: null if message is dismissed or string (can be empty) otherwise. 

{
	...,
	dialog: {
		...,
		prompt: func(string, string): Promise
	}
}

Confirm

confirm(message): Promise shows given message as confirmation message. The promise response data is: true (yes) or false (no). 

{
	...,
	dialog: {
		...,
		confirm: func(string): Promise
	}
}

Animation


Toti.animations

InputLoading

inputLoading(Node element): LoadingAnimation allows show loading animation on input or another element. In case of input element, the element must be parent element.
Animation is controlled using this methods:
  • start shows and start loading animation
  • stop stops loading animation. Animation is still visible.
  • failure switch animation to signalize invalid state
  • remove stops and remove loading animation

{
	...,
	animations: {
		...,
		inputLoading: func(Node element): LoadingAnimation
	}
}
