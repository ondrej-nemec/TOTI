Request and responses

Requests

URI parameters

Parameters in URI (/some/path/{param}) must be defined in method declaration.

Query parameters

Query parameters (/some/path?{key}={value}) are available at: 

		request.getQueryParams(); // returns collection of all parameters
		// OR
		request.getQueryParam(name); // returns parameter by given name as DictionaryValue

Body parameters

Body parameters can be:
  • URLEconded are automatically parsed
  • FormData are automatically parsed
  • Others available in binary form
Parsed parameters can be obtained: 

		request.getBodyParams(); // returns collection of all parameters
		// OR
		request.getBodyParam(name); // returns parameter by given name as DictionaryValue
		// file from FormData
		request.getBodyParams().getUploadedFile(parameterName); // returns UploadedFile
Binary data can be obtained: 

		request.getBody(); // returns byte[] or null if body is empty or data was parsed

UploadedFile

Structure holding data about uploading file: file name, content type, bom and file content.
Class also contains methods for helping with file saving: 

		UploadedFile file = ...;
		file.save(path); // save to given path
		file.save(path, filename); // save to given path with given name

Responses

Every response add all nesessary headers. 

		Response.create(statusCode)
		.addHeader(name, value) // can be called multiple times
		// HERE is correct body method

Empty

getEmpty() Response without body.

Text

getText(text) Response body will be plaintext.

Json

getJson(data) Response parse given data to json and send.

File

getFile(path) send content of file on given path to browser. Browser deside if shows file or download.
getFileDownload(sourceFile, fileName, force) send content of file on given path (sourceFile) to browser. File will be downloaded as fileName. If flag force is set to true, file will be downloaded.
getFileDownload(fileName, data, force) send binary data (data) to browser. File will be downloaded as fileName. If flag force is set to true, file will be downloaded.
This could be used to return pictures or runtime generated files.

Redirect

getRedirect(uri) redirect to given URI only inside current server.
getRedirect(uri, allowOutOfAppRedirect) redirect to given URI. If flag allowOutOfAppRedirect is set to true, redirect can be done outside current server.

Template

getTemplate(fileName, params) returns response with body parsed from given template. Requires registered TemplateExtension. Behaviour of this method depends on implementation of used extension.

WebSocket

WebSockets are handled little bit differently: 

	@Action(path="websocket")
	public ResponseAction getWebsocket() {
		return (request, identity)->{
			try {
				// websocket can be empty - means this request is not valid websocket request
				if (request.getWebsocket().isPresent()) {
					WebSocket webSocket = request.getWebsocket().get();
					webSocket.accept(()->{
						// on open
					}, (isBinary, byteBuffer)->{
						// on message
					}, (exception)->{
						// on error
					}, (message)->{
						// on close
					});
					return Response.getWebsocket(webSocket);
				}
				// any classic response
				return Response.OK().getEmpty();
			} catch (Exception e) {
				// some error handling
				throw new RuntimeException(e);
			}
		};
	}
