Package provide validation of request paramaters.

Create validator

Validator can be created using one of these factory methods: 


	boolean strictList = ...
	Validator v1 = Validator.create(strictList);
	Validator v2 = Validator.create(strictList, translator);
	Validator v3 = Validator.create(strictList, unexpectedParameters->customcustomErrorMessage);
	Validator v4 = Validator.create(strictList, unexpectedParameters->customcustomErrorMessage, translator);
strictList defines if validated parameters can (strictList=false) or cannot (strictList=true) contain other parameters.

Second option is create validator with default rule. The rule will be used to any unexpected parameter. 


	Validator v1 = Validator.create(d->d/* init defualt rule - see below */);
	Validator v2 = Validator.create(d->d/* init defualt rule - see below */, translator);
	Validator v3 = Validator.create(d->d/* init defualt rule - see below */, parametersNotMatchingDefaultRule->customcustomErrorMessage);
	Validator v4 = Validator.create(d->d/* init defualt rule - see below */, parametersNotMatchingDefaultRule->customcustomErrorMessage, translator);

Validate


	Validator v = ...;
	v.addRule(...);
	ValidationResult result = v.validate(requestParameters);

ValidationResult contains method isValid. Also provides all errors in getErrors(). All requerst parameters are parsed and available at getValues() (if not valid, data integrity is not guaranted).

Rules

Boolean


	v.addRule(r->r.booleanRules(name, required));
	// OR
	v.addRule(r->r.booleanRules(name, required, parameterName->messageIfParamerIsMissing));

	// in default rule
	Validator.create(d->d.booleanRules());

NULL value is consider as missing. "true", "on" and "1" is consider as true, any number higher than 0 is consider as true. Other values are consider as false.

Number

Convert parameter to number of given class. 


	v.addRule(r->r.numberRules(name, required, clazz));
	// OR
	v.addRule(r->r.numberRules(name, required, clazz, parameterName->messageIfParamerIsMissing));

	// in default rule
	Validator.create(d->d.numberRules(clazz));

Custom validation

Every parameter can be validated using custom validation. Custom validation is executed as last and only if parameter is valid. 


	v.addRule(r->
		r. /* set rule */
		.setCustomValidation(item->{
			item.addError("some error"); // if error is added, parameter is not valid
			Object raw = item.getRawValue(); // origin, not parset value
			Object parsed = item.getParsedVlaue(); // converted value
			item.setValue("anything"); // set new value
		})
	);

Custom validation

Every request parameters can be validated using custom validation. Available in Validator, map rules, list rules and sorted map rules. 


	v.setCustomValidation(item->{
		item.addError("some error"); // if error is added, parameters are not valid
		List<String> names = item.getItemsNames()); // list of parameter names
		Object value = item.getValue(name); // get parsed value by given name
		item.setItem(name, newValue); // set new value to given parameter
		item.removeItem(name); // remove given parameter
	})

Sub validator

Substructures as map and list require sub validator. Validator is created in rule definition. 


	v.addRule(r->
		r.mapRules(name, required, v1->
			v1.create(strictList)
			// define sub rules
			// OR
			v1.create(strictList, unexpectedParameters->customErrorMessage)
			// OR with default rule
			v1.create(d->d/*define rule*/)
			// OR
			v1.create(d->d/*define rule*/, parametersNotMatchingDefRule->customErrorMessage)
		)
	);
