Extensions

Extensions bring more functions and features. Every extension has to be registered: applicationFactory.addExtension(extension);.

How create own extension

Every extension implements Extension.
  • getIdentifier string unique
  • onRequestStart called before request is handled in controller
  • onRequestEnd called after request is handled in controller
  • onApplicationStart called when application starting
  • onApplicationStop called when application stopping

Template extension

Template extension is special case of extension. Allows to use getTemplate responses. Extensions must implements TemplateFactory and can be registered only one in application.
