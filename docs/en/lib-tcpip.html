Client

Client can be created in two ways: 


String url = "example.com";
int port = 80;
Protocol protocol = Protocol.HTTP_1_1;
Optional<SslCredentials> ssl = Optional.empty();
int timeOut = 60000;
Integer maxResponseBodySize = null;
Logger logger = ...;
HttpClient client = new HttpClient(url, port, protocol, ssl, timeOut, maxRespnoseBodySize, logger);

// OR
// port is 80 or 443 if SslCredentials are present
// other values have default value as defined in first example
HttpClient client = new HttpClient(url, protocol, ssl, logger);

Request callback

	request.addHeader("HeaderName", "HeaderValue");

	// set body: byte content
	request.setBody(new byte[] { ... });
	// OR set body: url encoded
	RequestParameters params = new RequestParameters();
	params.put("name", "value");
	request.setBodyUrlencoded(params);
	// OR set body: FormData
	RequestParameters params = new RequestParameters();
	params.put("name", "value");
	request.setBodyFormData(params);

Server

Server provides request catch and thread pool manage. Every client in halded in own thread. 


	int port = 80;
	int threadPool = 20; // how many clients can be served at once
	long readTimeout = 60000L;
	Optional<SslCredentials> ssl = Optional.empty();
	String charset = "utf-8";
	Logger logger = ...;
	Server server = new Server(port, treadPool, readTimeout, (socket, usedCharset)->{
		// your own handling
	}, ssl, charset, logger);
Manage server 

	server.start(); // start listening on given port
	server.pause(); // try pause listening
	server.stop(); // stop listening, close resources

SSL

If Optional<SslCredentials> is present, secured connection will be used.

Set certificates.

All setting is optional. 


	SslCredentials ssl = new SslCredentials();

	// server certificate
	String storeType = "JKS";
	ssl.setCertificateStore("/path/to/store", "storePassword", storeType);

	// set SNI validation
	ssl.setSniHostCheck(false); // default is true

	// set allowed clients
	ssl.setTrustedClientsStore("/paht/to/store", "storePassword", storeType);

	// set trust all clients
	ssl.setTrustAll(false); // default value is false, if trusted client store is set, default value change to false
