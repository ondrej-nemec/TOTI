Template file is usually HTML file with variables and some special tags - see below. Template syntax is similar to JSP, the .jsp extension is often used.

Variables

For using variable in template, package define syntax: ${variableName}. A result is ecaped, ff is written to final HTML.

Variable can be primite, String, null or any other object.

Non escaped value

If not escaped value is needed: ${variableName|noescape}.

Calling method of variable

If variable is object, they methods can be called: ${variableName.equals(123)} or ${variableName.getSometing()}. If object has attributes with getters, this is also posssible: ${variableName.something}

If variable is object, they methods can be called: ${variableName.equals(123)}.

Another variable can be used as parameter: ${variableName.equals(${anotherVariableName})}.

Variable can be casted: ${variableName|Integer.class}. Sometimes full class path will be necessary.

Code

Comment

Everyting between <%-- and --%> is commented. Variables inside are not replaced, nothing is executed.

Java code

Writting Java code directly in template could be hard and danger!

Everyting between <% and %> is pure Java code. Example: <% System.out.println("This"); %>.

Variables are not replaced here.

Returning Java code

Returning Java code allows do one line operation and return result. Result is not escaped. Variables will be replaced.

Example 1: <%= (123*321)%8 =%>. This will print 3 to template.

Example 2: <%= ${countOfGuests|int} > 5 ? "Too many" : "OK" =%>. This will print one of given texts to template.

Tags

Tags are special HTML like tags. Name of tags starts with t:. They run given login before final HTML is created.

Variables

Define variable

Define new variable. Visibility respects visibility in java, eg. variable in block is not visible outside. Variable is also available as ${} (with given visibility).

Tag: var
Paired: no
Parameters

  • name: name of variable
  • type: type of variable. Optional. Default value: java.util.Object
  • final: if present, variable is final
  • value: initial value. Optional. String value must be set like value='"something"'.

Set variable

Set value of already defined variable. Change appears in ${} too.

Tag: set
Paired: no
Parameters

  • name: name of variable
  • value: new value. String value must be set like value='"something"'.

Print variable

Print variable to template. Tag supports only variables defined in template.

Tag: out
Paired: no
Parameters

  • name: name of variable
  • noescape: if present, variable will not be escaped

Layout

layout

Define layout of template. Only one per template is allowed.

Tag: layout
Paired: no
Parameters

  • path: path to layout template relative to module path.
  • module: name of module where layout is. Optional. Default same as module of actual template.

Block

Define block of code for future usage. All parameters except listed below, are used as variables available as ${}.

Tag: block
Paired: yes
Parameters

  • name: block name

Include

Allows include defined block or another template. All parameters except listed below, are used as variables available as ${}.

If parameter block is present, block will be included. If parameter file is present, another template will be included.

Tag: include
Paired: no
Parameters for including block

  • block: name of defined block. If not existst, exception is thrown.
  • optional: if present, block will be included only if exists.

Parameters for including template
  • file: template path relative to module path.
  • module: module name. Optional. Default same as module of actual template.

Conditions

If

Check if condition is true.

Tag: if
Paired: both. Not paired works as if without braces.
Parameters

  • cond: Condition. Variables defined in template or ${} can be used. String must be in quotes.

Else If

Check if another condition is true. Must be always after if tag.

Tag: elseif
Paired: no, but must be finished with else or closing if tag.
Parameters

  • cond: Condition. Variables defined in template or ${} can be used. String must be in quotes.

Else

Else statement.

Tag: else
Paired: no, but must be finished with closing if tag.

Break

Break statement for if or elseif.

Tag: break
Paired:

Continue

Continue statement for if or elseif.

Tag: continue
Paired: no

Switch

Switch statement

Tag: switch
Paired: yes
Parameters

  • object: value than will be checked. Template defined variable or ${}.

Case

Case statement in switch.

Tag: case
Paired: both. Paired works like case with break, not paired works like case without break.
Parameters

  • cond: case value. String must be written like '"something"'

Default

Default statement in switch.

Tag: default
Paired: yes

Cycles

For

For statement

Tag: for
Paired: yes
Parameters

  • from: initial state. Required format: [type] [variableName]=[initialValue]. Variable is also available as ${}
  • to: closing condition.
  • change: change every iteration.

For Each

For Each for Map and List

If parameter map is present, tag iterate map. If parameter list is present, tag iterate list.

Tag: foreach
Paired: yes
Parameters for iterating map

  • map: the map than will be iterated. ${} also can be used.
  • key: key of each iterated item. Required format is [type] [variableName] or [variableName] (then type will be Object). Variable is also available in ${}.
  • value: value of each iterated item. Required format is [type] [variableName] or [variableName] (then type will be Object). Variable is also available in ${}.

Parameters for iterating list
  • list: the list than will be iterated. ${} also can be used.
  • item: each item. Required format is [type] [variableName] or [variableName] (then type will be Object). Variable is also available in ${}.

While

While statement

Tag: while
Paired: yes
Parameters

  • cond: Condition. Variables defined in template or ${} can be used. String must be in quotes.

Do While

Do-while statement. All parameters are defined in closing tag.

Tag: dowhile
Paired: yes
Parameters

  • cond: Condition. Variables defined in template or ${} can be used. String must be in quotes.

Try Catch

Try

Try statement.

Tag: try
Paired: yes

Catch

Catch statement. Must be between start and closing try tag.

Tag: catch
Paired: no
Parameters

  • name: name of exception variable. Exception variable is also available in ${}.
  • exception: expected exception. Optional. Default value is java.util.Exception.

Finally

Finally statement. Must be between start and closing try tag, or between catch and closing try.

Tag: finally
Paired:no

Others

Console outpu

Print result to system console.

Tag: console
Paired: no
Parameters

  • text: text, that will be printed.

Parameters

Parameters are special HTML attributes. They start with t:. They are parsed before creating final HTML.

This package supports paramters but not define any.
